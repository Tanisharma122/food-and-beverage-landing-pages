# Food and Beverage Landing Pages

Scroll-driven, interactive landing pages for food and beverage brands. Each page is a standalone portfolio demo built for a fictional brand.

## Pages

| Folder | Brand type | Style |
|---|---|---|
| `cafe/` | Cafe | Cosy and warm, with a menu highlight |
| `bakery-desserts/` | Bakery or dessert label | Soft pastel colours, with a reveal for each product |
| `festive-gifting/` | Festive gift hampers and sweets | Rich and celebratory, with an order call to action |
